### 伯努利数
伯努利数在很多的展开式中都见的到
> [!example] 定义
> 考虑计算函数  
>  $$
>  f(x) = \begin{cases}
>  \dfrac{x}{e^x - 1} & x \ne 0, \\
>  1 & x = 0
>  \end{cases}
>  $$
> 的 Maclaurin 展开式
> 算出来的系数就是伯努利数
> 具体而言：$$
> f(x) = B_0 + \frac{B_1}{1!}x + \frac{B_2}{2!}x^2 + \cdots + \frac{B_n}{n!}x^n + o(x^n) \ (x \to 0)
> $$

**具体的计算方法如下：**
首先，
$$
f(x) \cdot \frac{e^x - 1}{x} = f(x)\left[1 + \frac{x}{2!} + \frac{x^2}{3!} + \cdots + \frac{x^n}{(n+1)!} + o(x^n)\right] \equiv 1
$$
然后，我们把 $f(x)$ 的表达式表示出来
$$
f(x) = B_0 + \frac{B_1}{1!}x + \frac{B_2}{2!}x^2 + \cdots + \frac{B_n}{n!}x^n + o(x^n) \ (x \to 0)
$$
通过对比系数的方法我们就可以得到伯努利数的具体值
但是止步于此我们是不满意的，我们希望得到一个方法来得到显式表达 $B_n$
观察第 $x^n$ 项，我们有
$$
\sum_{i=0}^n\frac{1}{i!}\cdot \frac{B_{n-i}}{(n-i)!}=0
$$
再乘以一个 $n！$ 这个式子改写为
$$
\sum_{i=0}^nC_n^iB_i=0
$$
这个式子联想到二项式定理，



### 另外一个定义
接下来我们来看一些伯努利数更加原始的定义
一个我们经常在高中数学与物理题目见到的问题是：求 $\sum i^p$（记为 $s_p$）, 这个问题雅各布伯努利给了解决方案：
考虑一个裂项的式子
$$
\sum_{i=1}^{n}(i)^3-(i-1)^3=n^3-0
$$
再展开求和式子就可以了
$$
n^3=\sum_{i=1}^{n}(i)^3-(i-1)^3=3s_2-3s_1+s_0
$$
这样在我们知道 $s_1$ 的条件下我们就可以算出 $s_2$ 了
伯努利基于这个逻辑算出了 $p=9$ 的情况，列出如下
$$
\begin{aligned}
S _ { 0 }& = \frac { 1 } { 1 } ( n )\\
S _ { 1 }& = \frac { 1 } { 2 } \left( n ^ { 2 } + 2 \cdot \frac { 1 } { 2 } n \right)\\
S _ { 2 }& = \frac { 1 } { 3 } \left( n ^ { 3 } + 3 \cdot \frac { 1 } { 2 } n ^ { 2 } + 3 \cdot \frac { 1 } { 6 } n \right)\\
S _ { 3 } &= \frac { 1 } { 4 } \left( n ^ { 4 } + 4 \cdot \frac { 1 } { 2 } n ^ { 3 } + 6 \cdot \frac { 1 } { 6 } n ^ { 2 } + 4 \cdot 0 \cdot n \right)\\
S _ { 4 }& = \frac { 1 } { 5 } \left( n ^ { 5 } + 5 \cdot \frac { 1 } { 2 } n ^ { 4 } + 10 \cdot \frac { 1 } { 6 } n ^ { 3 } + 10 \cdot 0 \cdot n ^ { 2 } - 5 \cdot \frac { 1 } { 30 } n \right)\\
S _ { 5 }& = \frac { 1 } { 6 } \left( n ^ { 6 } + 6 \cdot \frac { 1 } { 2 } n ^ { 5 } + 15 \cdot \frac { 1 } { 6 } n ^ { 4 } + 20 \cdot 0 \cdot n ^ { 3 } - 15 \cdot \frac { 1 } { 30 } n ^ { 2 } + 6 \cdot 0 \cdot n \right)
\end{aligned}
$$
可以发现一个惊人的事实：
每一列中都有组合数身影，比如 $s_4$ 中的第三项就是 $C_5^2 \cdot \frac{1}{6}n^3$ 其他的地方也是类似的，而提取出组合数后剩下的系数就不再改变了
于是自然的，伯努利开始研究起了那些完全相同的系数
$$
B_0=1,B_1=\frac{1}{2},B_2=\frac{1}{6},B_3=0,B_4=\frac{1}{30},B_5=0\cdots
$$
伯努利数有一些性质
$$
\sum_{i=0}^nC_n^iB_i=0，B_{2k+1}=0
$$

$$
(B+1)^k=B^k
$$
在利用二项式定理展开后，把上标移到下标上，式子成立.
现在再看这个式子
$$
s_p=\frac{1}{p}(\sum_{i=0}^pC_p^iB_in^{p-i})
$$
这个式子和二项式展开非常像，
基于此，我们可以引申出伯努利多项式的概念
> [!example] 定义
> $$
> B_p(x)=(B+x)^p$$
> 为伯努利多项式

那么就有
$$s_p=\frac{B_p(n)-B_p(0)}{p}$$
